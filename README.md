# 台北驛傳 TAIPEI EKIDEN 2027

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository。
2. 將 `index.html`、`assets/` 和 `README.md` 上傳到 repository 根目錄。
3. 開啟 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/(root)`，按 **Save**。
6. 等待部署完成，GitHub Pages 會提供公開網址。

## 注意事項

- 網站提供個人報名、報名名單、主辦人五人分隊及 CSV 匯出。
- 報名資料使用瀏覽器 `localStorage`，只存在目前裝置/瀏覽器，不會跨裝置同步。
- 此為展示版，正式公開報名前請串接雲端資料庫及管理權限，避免以此版本收集真實個資。
- 路線及距離為目前規劃資料，活動前請再次確認。
